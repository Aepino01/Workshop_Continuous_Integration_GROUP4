## Gym Membership Quote

Command-line application that quotes the monthly cost of a gym membership.

Run the tests:

```
./mvnw -B test
```

Run the program:

```
./mvnw -B -q compile
java -cp target/classes ec.espol.gym.MembershipCli
```
